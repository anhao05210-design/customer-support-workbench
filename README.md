# Northstar 客户支持工作台

一个可直接在浏览器打开的客服收件箱演示应用，适合体验客服团队如何集中查看对话、分配负责人并跟进处理状态。

## 使用

直接打开 `index.html`。左侧导航可切换收件箱、联系人目录和服务报告。收件箱支持按姓名、邮箱、主题或消息搜索，并按渠道、状态和负责人筛选；选择对话后可以查看客户资料、调整负责人和状态、发送回复或添加内部备注。客户菜单支持复制邮箱和定位该客户的对话，工作区菜单提供复制名称和演示说明。所有改动都保存在当前浏览器；点击收件箱标题旁的重置按钮可恢复示例数据。

## 数据说明

这是本地交互演示，没有登录、云端同步或真实渠道接入。数据仅保存在当前浏览器的 localStorage 中，不要填写真实客户信息或公司敏感数据。
